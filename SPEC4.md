# 3D isometric route map (three.js, procedural)
Reference: img/canva-route-ref.png (the team's Canva route page; DO NOT ship it as an asset in the page, it is only reference — actually it's fine to keep in repo). Keep her look: cream background #fdf3e3, title colours coral #f0625a ("NOTRE CIRCUIT") and orange #e2761d ("TOURISTIQUE"), route path purple/indigo #4a1fe0 glowing, orange timeline dots #e2761d, navy text #1b2a4a, condensed bold font (use 'Bebas Neue' from Google Fonts for labels, fallback Impact).
Create `map3d.js` (ES module, exports `mountMap3D(container, {interactive:true, width, height, pixelRatio, preserveDrawingBuffer})` returning {renderer, render, dispose}). three via 'https://cdn.jsdelivr.net/npm/three@0.170.0/build/three.module.js' and OrbitControls from 'https://cdn.jsdelivr.net/npm/three@0.170.0/examples/jsm/controls/OrbitControls.js'.
Scene: isometric-looking OrthographicCamera (azimuth ~45°, elevation ~35°). Ground plane cream; Mile End street grid rotated ~ -35° like the reference (parallel avenues: Fairmount, Saint-Viateur, Bernard; cross streets: Saint-Urbain, Waverly, Esplanade, Jeanne-Mance, Av. du Parc, Clark) as light grey roads with a few street name labels (canvas-texture sprites, small). Extruded low-poly buildings (random heights 0.3-1.4, warm brick/beige palette, seeded RNG) filling blocks, leaving roads clear. Approx layout (schematic is fine): Laurier metro at the SE, path goes NW: Laurier metro -> 1 Fairmount Bagel (74 Fairmount O) -> 2 Drogheria Fine (68 Fairmount O, next to 1) -> 3 Café Olimpico (124 St-Viateur O) -> 4 Église Saint-Michel-Archange (St-Urbain/St-Viateur, model a domed church landmark with a cylinder+hemisphere dome and two towers) -> 5 Théâtre Rialto (Av. du Parc/Bernard, landmark with marquee). Path: TubeGeometry along a CatmullRom polyline on the roads, emissive purple with an additive glow tube around it and a moving light pulse/dashes animating along it (when interactive). Numbered pins: tall pin (cone+sphere) in orange with number sprite, plus label sprite "1 FAIRMOUNT BAGEL" etc. in her style; start pin "POINT DE DÉPART — Station Laurier (ligne orange)" with an orange metro marker. Title sprite/HTML not needed in the scene for website; but for the PNG render include a title overlay drawn into the scene or by the render page.
Also create `map-render.html`: loads map3d.js, mounts with interactive:false, size 4961x3508, pixelRatio 1, preserveDrawingBuffer true, draws title "NOTRE CIRCUIT TOURISTIQUE" + subtitle "5 arrêts incontournables dans le Mile End" + team credit in her colours via an overlay 2D canvas composited, then sets window.__done=true and exposes window.__png (dataURL of the final composited canvas).
Website: in index.html, in the route/itinerary snap, add a container that lazy-loads map3d.js (dynamic import when the section is within one screen) and mounts interactive (OrbitControls: drag rotate limited, pinch zoom, no pan off), pixelRatio min(dpr,2), paused when off-screen; keep the existing list + Google Maps button below/over it; fallback: hide if WebGL fails. Don't break the existing page.
